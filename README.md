# Inventory App

## Project Structure

- `index.html` — Login
- `page/dashboard.html` — Business Dashboard
- `page/dashboard-stock.html` — Stock Dashboard
- `page/customers.html` — Customer Management
- `page/revenue.html` — Revenue
- `css/` — Stylesheets
- `js/` — JavaScript files
